The product screenshots are staged demo renders of the actual extension UI on representative trading page layouts. They use sample token and wallet data. Capture a live installed extension on each site before submitting if you want the Store listing to show exact current site layouts. Never include your account, wallet address, private key, or session data in public screenshots.

The Store upload archive is `CallMeOut-WebStore.zip` in the project root. Its `manifest.json` is at the ZIP root. The ZIP is a release artifact and is intentionally excluded from Git.
